Features

Know where you stand before you hit the limit

No more opening settings to check. Limitly keeps the number where you can see it.

5-hour and weekly

Both limits side by side, per-model weekly limits, and the exact time each one resets.

Always on screen

A colour-coded percentage on the toolbar and tray icon: green, amber, then red as you get close.

Alerts before you run out

A notification when 20%, and then 5%, of a limit is left.

Know when you'll run out

From your recent pace: “At this pace, you'll run out by 3:40.”

24-hour history

A simple chart of how your limit moved over the last day.

Refreshes itself

Every 5 to 60 minutes (10 by default), and it waits patiently when claude.ai asks it to slow down.

Arabic and English

A full right-to-left Arabic interface, plus light and dark themes that follow your system.

Private by design

Talks only to claude.ai with your own session. No accounts, no analytics, no servers of ours.

Light and up to date

The Windows app is a few MB, starts with Windows and installs its own updates.

Get Limitly

Limitly for Windows

Windows 10 and 11 · 64-bit

Download installer.exe Microsoft StoreComing soon
  1. Run Limitly-Setup.exe.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway.
  3. Click Sign in to Claude and sign in once.
  4. Limitly shows up on the taskbar. If it’s hidden under ^, drag it onto the taskbar.
Starts with Windows and updates itself. You can turn off auto-start in Settings.

Limitly for Chrome

Google Chrome and Chromium browsers

Download extension.zip Add to Chrome Chrome Web StoreComing soon
  1. Download the .zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin Limitly from the extensions icon, and make sure you’re signed in to claude.ai.
Keep the unzipped folder where it is. Chrome loads the extension from it.

FAQ

Questions

Is Limitly made by Anthropic?

No. Limitly is an independent project and is not affiliated with or endorsed by Anthropic.

Can it read my conversations?

No. It only asks claude.ai for the usage figures you can already see on claude.ai’s usage page. It never opens your chats, files or prompts.

Do I need an API key?

No. Limitly uses your normal claude.ai sign-in. In Chrome it uses your browser session; on Windows you sign in once inside the app.

Why does Windows warn me when I install it?

The app isn’t signed with a paid code-signing certificate yet, so SmartScreen doesn’t recognise it. Every release is built automatically by GitHub Actions and checked before it is published.

How do I get updates?

The Windows app checks for new versions and installs them for you. For the Chrome extension, download the new .zip and replace the folder, then click reload on chrome://extensions.

Is it free?

Yes, completely free, with no ads and no accounts.

Does it work with the Free plan?

Not yet. claude.ai doesn't show usage limits for Free accounts, so there is nothing to read. Limitly says so clearly instead of showing an error. It works with paid plans such as Pro and Max.

Will checking my usage cause problems with claude.ai?

No. Limitly checks every 10 minutes by default and never more than once every 30 seconds. If claude.ai asks it to slow down, it waits exactly as long as asked, backs off further if needed, and keeps showing your last numbers meanwhile.

Your data stays with you

  • Usage figures come only from claude.ai, using your own session.
  • Results and settings are stored on your device only.
  • No analytics, ads or tracking. Nothing is sent to the developer.
